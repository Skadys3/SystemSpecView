# 🖥️ SystemSpecView

**SystemSpecView** — лёгкое настольное приложение для мониторинга характеристик компьютера и состояния системы в реальном времени.

Приложение предоставляет единый интерфейс для просмотра информации о **процессоре, оперативной памяти, дисках, сети, видеокарте, материнской плате, батарее и запущенных процессах**.

Интерфейс построен на **CustomTkinter** и поддерживает светлую и тёмную темы.

---

## ✨ Возможности

### 📊 Системный дашборд

На главном экране отображаются основные показатели компьютера:

* загрузка CPU;
* использование RAM;
* состояние дисков;
* сетевой трафик;
* информация о GPU;
* состояние батареи;
* время работы системы;
* краткая информация об оборудовании;
* графики изменения показателей в реальном времени.

Для CPU и RAM используются кольцевые индикаторы и небольшие графики — это позволяет быстро оценить текущее состояние системы.

### ⚙️ Процессор

* общая загрузка CPU;
* загрузка каждого ядра;
* текущая частота;
* количество физических и логических ядер;
* информация о процессоре;
* график нагрузки.

### 🧠 Оперативная память

* общий объём RAM;
* используемая память;
* свободная память;
* процент использования;
* использование swap/pagefile;
* история изменения нагрузки.

### 💾 Диски

Для каждого доступного раздела отображается:

* буква/точка монтирования;
* занятое пространство;
* общий объём;
* свободное пространство;
* процент использования;
* визуальный индикатор заполнения.

### 🌐 Сеть

SystemSpecView позволяет просматривать сетевые интерфейсы и статистику:

* название адаптера;
* IP-адрес;
* MAC-адрес;
* состояние интерфейса;
* отправленный трафик;
* полученный трафик;
* сетевые подключения.

### 🎮 Видеокарта

Для GPU отображается:

* название видеокарты;
* производитель;
* версия драйвера;
* объём видеопамяти;
* используемая видеопамять;
* разрешение дисплея.

Для NVIDIA GPU используется **NVML**, если библиотека доступна в системе.

### 🖥️ Материнская плата и BIOS

На поддерживаемых системах отображается:

* производитель материнской платы;
* модель;
* версия BIOS;
* серийный номер.

### 🔋 Батарея

Для ноутбуков:

* текущий заряд;
* состояние питания;
* подключение к сети;
* оставшееся время работы.

### 📋 Диспетчер задач

Встроенный менеджер процессов предоставляет информацию о запущенных программах:

| Параметр | Описание                 |
| -------- | ------------------------ |
| PID      | Идентификатор процесса   |
| Name     | Имя процесса             |
| User     | Пользователь             |
| CPU      | Использование процессора |
| Memory   | Использование памяти     |
| Disk I/O | Дисковые операции        |
| Network  | Сетевые подключения      |
| Threads  | Количество потоков       |

Поддерживаются:

* сортировка по столбцам;
* поиск;
* фильтрация;
* завершение процессов;
* просмотр свойств процесса.

> Для завершения некоторых системных процессов могут потребоваться права администратора.

## 📄 Экспорт данных

SystemSpecView позволяет экспортировать собранную информацию о компьютере.

Поддерживаемые форматы:

* **JSON** — для дальнейшей обработки программами;
* **TXT** — для обычного просмотра и передачи информации.

Экспорт может быть полезен при:

* диагностике компьютера;
* обращении в техническую поддержку;
* сравнении конфигураций;
* документировании оборудования.

# 🚀 Установка

## Требования

* Python **3.10+**
* Windows / Linux / macOS — в зависимости от доступности системных API
* Git — для клонирования репозитория

Некоторые возможности являются платформозависимыми.

В частности, получение информации о материнской плате и BIOS через WMI относится к Windows.

---

## 📥 Клонирование репозитория

```bash
git clone https://github.com/Skadys3/SystemSpecView.git
cd SystemSpecView
```

---

## 📦 Установка зависимостей

Создайте виртуальное окружение:

### Windows

```powershell
python -m venv .venv
.venv\Scripts\activate
```

### Linux / macOS

```bash
python3 -m venv .venv
source .venv/bin/activate
```

Затем установите зависимости:

```bash
pip install -r requirements.txt
```

---

## ▶️ Запуск

```bash
python main.py
```

### Windows

Для получения максимального количества системной информации рекомендуется запускать приложение с правами администратора.

Это может быть необходимо для:

* доступа к некоторой информации WMI;
* получения отдельных системных параметров;
* завершения системных процессов.

# ⚡ Производительность

Приложение использует несколько подходов для уменьшения нагрузки на CPU и GUI.

### Фоновый сбор данных

Системные данные собираются в отдельном потоке, чтобы операции мониторинга не блокировали интерфейс.

```text
GUI Thread
    │
    ├── отображение
    ├── навигация
    └── обработка событий

Background Thread
    │
    ├── CPU
    ├── RAM
    ├── Disk
    ├── Network
    ├── GPU
    └── Processes
```

### Обновление только активной страницы

Нет необходимости постоянно перерисовывать все страницы приложения.

Обновляются только элементы текущего представления.

### Dirty checking

Canvas-компоненты проверяют, изменились ли данные перед перерисовкой.

Это используется, в частности, для:

* `Sparkline`;
* `RingGauge`;
* `ProgressStatCard`.

### Кэширование

Некоторые редко изменяющиеся параметры кэшируются:

* имя пользователя процесса;
* время создания процесса;
* имя CPU;
* информация о материнской плате;
* сетевые подключения;
* дисковые I/O-счётчики.

Это уменьшает количество дорогостоящих системных запросов.

## 📌 О проекте

SystemSpecView создан как компактный локальный инструмент для получения подробной информации о компьютере без необходимости использовать несколько отдельных системных утилит.

Основная идея проекта — объединить **мониторинг оборудования, системную информацию и управление процессами** в одном понятном графическом интерфейсе.
